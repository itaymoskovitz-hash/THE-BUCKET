# The Bucket — רשימת קניות משפחתית

אפליקציית ווב בעברית לניהול רשימת קניות משותפת, עם חשבונות, משפחות, הזמנות וסנכרון בזמן אמת.

## מבנה

```
app/                      ← זה כל האתר. את התיקייה הזו מעלים לאחסון.
  index.html
  css/app.css             ← עיצוב (צבעים בראש הקובץ, תחת :root)
  js/config.js            ← כתובת Supabase ומפתח ציבורי (publishable). אין כאן סודות.
  js/categories.js        ← מילון הקטגוריות. להוסיף מילה = להוסיף אותה לרשימה המתאימה.
  js/...                  ← שאר הקוד
  assets/logo.svg         ← לוגו. להחלפה: שמרו קובץ חדש באותו שם.
  assets/favicon.svg      ← אייקון לשונית. להחלפה: אותו דבר.
  assets/apple-touch-icon.png, icon-512.png ← אייקון למסך הבית בטלפון
supabase/migrations/001_init.sql   ← מבנה מסד הנתונים, ההרשאות והפעולות המוגנות (כבר הוחל)
supabase/tests/rls_test.sql        ← בדיקת אבטחה (רצה בתוך טרנזקציה ומתבטלת בסוף)
tests/                             ← בדיקות תצוגה עם שרת מדומה (לא נכלל באתר)
DEPLOY.md                          ← מדריך העלאה לאוויר, בשפה פשוטה
```

## משתני סביבה

אין צורך במשתני סביבה ואין שלב build. שני הערכים היחידים נמצאים ב־`app/js/config.js`:

| שם | מה זה | סודי? |
|---|---|---|
| `SUPABASE_URL` | כתובת הפרויקט | לא |
| `SUPABASE_PUBLISHABLE_KEY` | מפתח ציבורי (`sb_publishable_…`) | לא – מיועד לדפדפן. ההגנה היא ה־RLS במסד |
| `CONTACT_EMAIL` | מייל ליצירת קשר שמוצג בדפים המשפטיים | לא |

**אסור** להכניס לקוד: מפתח `service_role` / `sb_secret_…`, סיסמת מסד נתונים, או כל סוד אחר.
האפליקציה לא צריכה אותם – כל הפעולות הרגישות רצות כפונקציות מוגנות בתוך Postgres.

## אבטחה בקצרה

- RLS פעיל על כל 4 הטבלאות. משתמש רואה/עורך רק משפחות שהוא חבר בהן.
- אין הרשאת כתיבה ישירה ל־`family_members` ול־`family_invitations`. שינויי חברות עוברים רק דרך פונקציות `SECURITY DEFINER` שבודקות הרשאה בפנים.
- הזמנה: טוקן אקראי של 256 ביט, נשמר רק כ־SHA-256, תוקף 7 ימים, חד־פעמי, מחייב שהמייל המחובר (והמאומת) זהה למייל המוזמן.
- טריגר במסד מונע העברת פריט בין משפחות ושינוי יוצר/תאריכים.
- התראות ה־Supabase Advisor שנשארו ("signed-in users can execute SECURITY DEFINER function") צפויות: אלה בדיוק הפונקציות שהאפליקציה קוראת להן, וכל אחת בודקת הרשאה בעצמה.
